📦 Installation & Setup Guide

Recova Studio is distributed via Microsoft Store and direct packaging formats for Windows 10/11 x64 systems:

1. Microsoft Store (Official Verified Release)

The safest, fastest, and most convenient way to install and maintain Recova Studio with zero configuration:

🛍️
Store Page: Open the Official Microsoft Store Listing and click Install. Automatically maintained with silent background updates.

2. Windows MSIX Package (Direct Download)

The modern Windows Store application package (.msix) offers sandboxed security, automated zero-clutter uninstallation, and seamless background updates.

💡
Quick Install: Double-click Recova-Studio-v1.1.1.msix to open the native Windows App Installer, then click Install.

If your system requires installing the self-signed test certificate into your local Trusted Root store, run this one-line PowerShell command in an elevated prompt:

# Install MSIX directly via PowerShell: Add-AppxPackage -Path ".\Recova-Studio-v1.1.1.msix"

2. Traditional Setup Installer (.exe)

For users who prefer classic Windows desktop applications with customizable installation folders and Start Menu shortcuts, run Recova-Studio-Setup-v1.1.0-x64.exe.

3. Portable Executable (.exe)

Recova-Studio-Portable-v1.1.0-x64.exe runs directly from any folder or USB thumb drive without writing to registry keys or requiring administrator privileges.

🚀 Quickstart Guide

Get your first cinematic video created and exported in less than 3 minutes:

  1. Select Capture Source: Choose Full Screen, Specific Window, or Custom Area.
  2. Configure Audio & Camera: Toggle System Audio (WASAPI loopback) and Microphone. Optionally enable the floating Webcam Bubble.
  3. Start Recording: Press Ctrl+Shift+R or click the red Record button. The floating HUD timer will appear.
  4. Stop Recording: Press Ctrl+Shift+S. The project automatically loads into the Recova Studio Video Editor.
  5. Add 3D Mockup: In the right Inspector panel, click Device Mockups and select MacBook Pro 16" or iPhone 16 Pro.
  6. Generate Captions: Click Auto-Captions and select Transcribe with Whisper. Word-by-word karaoke text appears automatically!
  7. Export 4K Video: Click Export Video on the top right, pick your bitrate preset, and render with NVIDIA NVENC.

🎥 Screen & Audio Recording Architecture

Recova Studio uses native low-level Windows APIs for zero dropped frames and ultra-low CPU consumption:

  • Windows Graphics Capture (WGC) API: Hardware-accelerated desktop capture bypassing slow GDI pipelines, capable of smooth 4K 60FPS even under heavy 3D gaming load.
  • WASAPI Audio Loopback: Direct digital capture of Windows system audio at 48kHz without virtual audio cables or sound degradation.
  • Floating Recording HUD: A discreet, draggable mini-controller that remains invisible to your recording while letting you pause, resume, or restart at any moment.

🎛️ Multi-Track Timeline & Editing (NLE)

The timeline in Recova Studio is built on an ultra-responsive WebGPU / HTML5 Canvas rendering engine supporting 120Hz smooth scrolling and scrubbing:

  • Video Track (V1): Holds your screen footage, clips, and cuts.
  • Zoom Regions Track: Visual indicators for camera zooms with dynamic spring damping.
  • Audio Tracks (A1 / A2): Separate channels for desktop audio and microphone with live peak meters.
  • Captions & Subtitle Track: Independent timing blocks for karaoke cues and kinetic title overlays.

🎚️ Ripple Edit & Auto-Gap Removal

Say goodbye to manually dragging clips to close empty spaces after making cuts. Recova Studio includes full CapCut-style Ripple Delete functionality:

⚡
Keyboard Shortcut: Press Shift+Delete or X to Ripple Delete the selected clip.

When Ripple Delete is executed:

  1. The selected clip region is removed from the timeline.
  2. All subsequent video clips are automatically shifted left to fill the exact gap.
  3. Synchronized audio tracks, zoom regions, annotations, and karaoke caption cues are shifted simultaneously, preserving complete AV sync.

⚡ Speed Curves & Velocity Ramping

Recova Studio lets you create professional pacing using Bézier speed curves rather than flat, boring speed multipliers:

  • Montage Curve: Fast entry (2x) → Dramatic slow-motion middle (0.5x) → Fast exit (2x). Perfect for showcasing UI workflows.
  • Hero Shot: Normal (1x) → Extreme slow-mo focus (0.3x) → Normal (1x). Ideal for high-impact button clicks.
  • Bullet Time: High velocity (3x) → Matrix-style slow crawl (0.2x) → High velocity (3x).
  • Jump-Cut Hyper: Fast-forward burst (4x to 8x) for long typing or loading screens.

📱 Smart Auto-Reframe (9:16 Shorts & TikTok)

Repurpose widescreen landscape captures into vertical content without losing the action:

  • When switching aspect ratio from 16:9 to 9:16, Recova Studio reads the recorded cursor coordinates.
  • The camera window centers dynamically around mouse clicks and active UI regions.
  • Configurable Smoothing Factor and Deadzone Radius prevent distracting micro-jitters, creating a smooth, handheld camera glide.

❄️ Freeze Frames & Filmstrip Visualizer

Highlight important moments by freezing video playback while allowing voiceover and annotations to continue:

  • Press F at any playhead position to insert a 2-second freeze frame.
  • Extend or shorten the freeze duration by dragging its edge on the timeline.
  • The Filmstrip Visualizer displays thumbnail frames along the timeline track for quick visual navigation.

🔧 Troubleshooting & FAQ

Q: Windows displays "Unknown Publisher" or Certificate Warning when installing MSIX.

Because Recova Studio is an independent open-source release signed with a developer certificate, Windows SmartScreen may ask for confirmation:

  1. Right-click Recova-Studio-v1.1.1.msix → Properties → Digital Signatures tab.
  2. Select the certificate → Details → View Certificate → Install Certificate.
  3. Select Local Machine → Place certificate in Trusted Root Certification Authorities.
  4. Alternatively, use Recova-Studio-Setup-v1.1.0-x64.exe which does not require root certificate installation.

Q: Does Whisper AI require an internet connection?

No. Recova Studio bundles lightweight local Whisper ONNX / WASM runtimes. All speech-to-text recognition occurs 100% on your local machine with zero telemetry or network transmission.

Q: Why is NVENC hardware acceleration greyed out?

Ensure you have an NVIDIA GeForce GTX 1050 or newer GPU and your display driver is updated to version 530+ or newer. If no dedicated GPU is detected, Recova Studio seamlessly falls back to high-performance multi-threaded CPU encoding.
